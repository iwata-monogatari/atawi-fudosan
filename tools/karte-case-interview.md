# 実家カルテ利用事例の取材・掲載ひな型

会社の不動産成約事例、実際のカルテ利用事例、再構成した解説、架空の見本を区別する。

## 記録する項目

| 項目 | 内容 |
|---|---|
| 相談時期・対象地域 | 年月と、公開可能な市町村まで |
| 相談前の迷い | 何が分からず、どの判断が止まっていたか |
| カルテで確認したこと | 確認できた事実、資料・確認日、未確認の点 |
| 家族の判断 | 売る・残す・貸す・話し合い継続など、実際の方針 |
| その後の行動 | 実際に行ったことだけ。方針と行動を混同しない |
| 未確認・未完了の点 | 残っている確認、まだ済んでいない行動 |
| 掲載範囲 | 匿名化、写真、地域、価格、家族の事情など |
| 掲載内容確認 | 確認者・確認日・確認済みの掲載文を非公開案件記録に保存 |

## トップ用の短いひな型

- 見出し：［判断が進んだこと］
- 相談前：［迷い］
- 確認したこと：［カルテで分かった事実］
- 家族が決めたこと：［実際の方針］
- 相談年月・市町村・実家カルテ利用事例の表示

## 2026年10月14日掲載の事例

運営者からこの実装依頼の会話で提供された情報を、匿名で掲載した。

- 2026年9月、磐田市、農地。
- 相談前：どこに相談したらよいか分からなかった。
- 確認：農地の建築要件がなく、引き渡しを進められない状況だった。
- 判断：引き続き農地を持ち続けることにした。
- 価格、相談者の属性、具体的な法的手続き、その後の管理状況は提供されていないため補っていない。
