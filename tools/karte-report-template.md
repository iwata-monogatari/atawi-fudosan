# 実家カルテ 担当者用の受付とレポートひな型

2026年10月14日、運営者が確認した運用に合わせて更新。公開見本は架空例であり、見本の数値を実物件へ転記しない。

## 受付と期限の記録

| 記録 | 内容 |
|---|---|
| 受付日・受付経路 | 申込みを受けた日、フォーム・電話・LINE等 |
| 希望する初回連絡方法 | メールまたは電話。希望した方法で初回連絡 |
| 初回連絡日 | 原則2営業日以内。受付日の翌営業日から数え、水曜・日曜・臨時休業日を除く |
| 不足情報 | 物件特定や作成に必要な情報。案件ごとに伝える |
| PDFの受取方法と送付先 | 希望するメールまたはLINEと、確認済みの送付先 |
| 必要情報と送付先がそろった日 | 納品の起点。後日の社内処理日へ置き換えない |
| PDFの送付期限 | 起点の日を除き、翌日を1日目として翌々日まで。土日も数える |
| 実際の送付日 | 作成完了や送信失敗、連絡試行を送付済みとしない |

情報不足は必要な情報がそろってから渡す。送付先不明は確認してから作成する。期限のために暫定カルテや不足情報の連絡を納品扱いにしない。

金曜に条件がそろった場合、土曜が1日目、日曜が2日目で、日曜までにPDFを送る。休日をまたぐ案件にも担当と期限を決める。納品期限が先に来る場合は、初回連絡の最長目安まで待たず必要な連絡を行う。

## 納品形式

PDFを希望するメールまたはLINEで送る。Web見本は基本的な内容のイメージ。内容とページ数は物件によって変わり、詳しい3ページPDF見本と同じページ数を固定で約束しない。来店・郵送は例外の個別対応。送料を確認せず無料郵送を約束しない。

## 基本の要約

| 欄 | 記入する内容 |
|---|---|
| 対象物件 | 対象とした土地・建物、物件種別、確認が必要な所有者との関係 |
| 価格の目安 | 個別の根拠、算定日、比較条件、変動し得る点。出せない場合は理由と次の確認 |
| 分かったこと | 資料名・確認日・確認できた範囲 |
| これから確認すること | 未確認事項。未確認を欠陥や違反と決めつけない |
| 次の対応 | 優先する1〜3件と担当先。売る・残す双方の判断材料 |

必要に応じて確認表と対応の順序を加える。資料による確認、家族への確認、現地未確認、個別照会、専門家の判断を区別する。法律・税・測量・建物検査の個別判断を、カルテの整理だけで完了したと扱わない。

## 無料範囲と専門家への依頼

- カルテの作成、価格の目安・確認点・次の対応の整理は無料。
- 登記情報・公図等、必要な資料の取得実費も無料。
- 必要な現地確認・訪問査定・役所等への確認も無料。
- 専門家の紹介と見積もり取得は当社で支援。測量・表題登記・接道等の専門家業務の実務費は各専門家がお客様へ請求する。
- 専門家の業務内容と見積もりをお客様が確認してから依頼する。カルテの申込みだけを依頼への同意にしない。
- カルテに関する質問・修正・再発行・家族同送は無料、回数制限なし。同送の希望と宛先を確認する。

## 送付前の確認

1. 対象物件・算定日・根拠・未確認事項が正しく記載され、架空の数値や事例名が残っていない。
2. 金額を出せない場合は理由と次の確認を記載した。
3. 必要な情報と送付先がそろった日、翌々日の期限、完成版を確認した。
4. メールかLINEの希望、宛先、送るPDFが一致している。
5. 料金と確認範囲が申込み時の説明と一致し、見積もり確認前に専門家業務へ進めていない。
6. 実際の送付を記録し、質問・修正・再発行等へ初回納品と同じ返答期限を無断で追加しない。
