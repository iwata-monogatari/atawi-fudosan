# 実家カルテ：担当者用レポート雛形

この雛形は実際の依頼ごとに宅建士が確認して作成する。公開中の[構成見本](/karte/sample/)は架空事例であり、見本の金額を実物件へ転記しない。

## 受付後

- 受付日、受付経路、希望する初回連絡方法を記録する。メール希望者へ電話での初回回答を強制しない。
- 物件所在地・所有者との関係・調査対象を確認する。不足情報や回答の目安は受付後に案内する。
- 写真、固定資産税通知書、権利証等は必要な場合に任意で案内する。初回フォームで必須にしない。
- 追加の現地調査・測量・登記等は標準カルテから切り離す。希望を受けた場合だけ内容と費用を提示し、合意前に着手しない。

## 1ページ目：判断のための要約

|欄|記入内容|
|---|---|
|対象物件|所在地、物件種別、対象とした土地・建物、所有者との関係で確認が必要な点|
|机上の価格目安|概算レンジまたは「算定不能」。算定日、参照した事例・資料、面積・建物状態などの仮定、現地確認で変動し得る点|
|確認済みの事実|資料名と確認日を付して列挙。登記、地積、接道、用途地域等を必要な範囲で|
|未確認事項|確認できていない情報。未確認を直ちに欠陥・違反と表現しない|
|価格・手続きへの影響|事実と条件付きの推測を区別し、なぜ次の確認が必要かを記入|
|売る場合|最初に誰が何を確認するか。片付け・解体・修繕を一律に勧めない|
|残す場合|管理、費用、家族の役割など検討事項。分からない金額を創作しない|
|対応順序|優先する1～3件と担当先。会社でできること、外部専門家が担うことを分ける|

## 2ページ目以降：確認資料と支援

- 参照資料の一覧と確認日。
- 名義・権利・土地・道路・農地・災害・建物のうち当該物件に関係する詳細。
- 法律・税・測量・建物検査に属する判断は、必要に応じて専門家へ確認する事項として記載。
- 標準カルテと机上価格目安、標準的な資料取得は継続して無料。追加支援は任意と明記。

## 送付前チェック

1. 価格が個別の根拠に基づき、対象物件と算定日が明記されている。
2. 価格が出せない場合は理由と次の確認を記載した。
3. 見本の架空数値や事例名が残っていない。
4. 料金、連絡方法、対象物件、回答内容が申込み時の案内と一致している。
5. 担当者が内容を確認し、本人に約束していない有料業務を開始していない。
