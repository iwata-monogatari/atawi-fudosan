# 実家の写真・現地確認メモ

公開先 `/jikka/visit-memo/`。2026年10月12日版の企画書と作成指示書に基づく初版。固定12項目を記録する。確認済みは利用者の観察であり、安全性や売却可能性の判定ではない。写真ありは手元の記録を意味し、画像を本ツールへ取り込まない。

通常はメモリ内で保持。編集用保存を本人が選んだ場合のみJSONを端末へ生成する。外側はkind=atawi-jikka-visit、fileVersion=1、savedAt、memo。32KiB以下、memoは16KiB以下。保存ファイルに30分の期限はなく、本人が選んで端末内で再開する。ファイル名に物件情報を含めず、取込み内容をサーバーに送らない。

相談添付を選んだ場合はsessionStorageの `atawi_jikka_visit_handoff_v1` にschemaVersion、createdAt、memoを保持。同一タブのフォームへvisit=1で引き継ぎ、30分の期限を読込み・復帰・表示中・送信前で検証する。無効化が起きた場合は次の送信前に本人の再確認を求める。解除・送信成功では自分のキーだけを削除する。

比較メモと現地メモは独立したチェックと全文表示を持つ。他方の有効な一時メモは本人が全文を開いて添付を選ぶことで追加できる。メモなし・比較のみ・現地のみ・両方の4経路を維持し、500文字欄へ転記しない。APIは各メモを共通モジュールで再検証し、件数・確認事項を通知本文へ生成する。不正な一方があれば受付を拒否する。通知先・通常フォーム・写真入口は既存どおり。

印刷は一覧A4一枚、自由記入がある場合のみ詳細一枚を追加。最大入力でも2枚以内、本文10pt以上。改行と連続空白は印刷時のみ空白1つへ整え、保存データは維持する。共通フッターや操作類は隠す。

計測はjikka_visit_start、result_view、print_requested、export_requested、import_success、consult_click、application_success。メタデータは固定tool=jikka-visit-v1、step、許可済みentryのみ。メモ本文・所在地・ファイル名を計測やログに入れない。通常のform_consultと補助イベントを合算しない。

受付後は、本人が見た記録と専門確認を分けて扱う。確認できなかった項目を理由に相談を断らず、現地確認の要否と本人の希望を整理する。カルテ作成に必要な現地確認は無料。測量・登記等の専門家業務は当社が紹介して見積もりを取得し、各専門家がお客様へ請求する。案件管理では物件確認、現地確認の相談、売却相談、媒介契約を区別し、30・60・90日の検討に利用する。

検証はNode全テスト、公開情報チェック、差分チェック、Pages Functionsビルド。ブラウザーで保存と翌日相当の再開、最大印刷、320〜1280px、200％拡大、期限切れ、二種類の添付、解除、失敗と重複防止を確認する。実機未確認の端末は引渡し結果に記録する。通知は模擬環境で検証し、本番へ架空の申込みを送らない。

既存GitHub連携からCloudflare Pagesへ公開し、公開コミットと試験記録は作業出力フォルダーに残す。他の変更を保持して統合し、切戻しは今回のコミットを対象とする。
