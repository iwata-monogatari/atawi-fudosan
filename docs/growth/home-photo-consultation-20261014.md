# トップページ・写真・カルテ利用事例の実装記録

## 公開内容

- 冒頭の直接申込みと見本への入口を、任意の状況選択より前に置く。
- 主な順番は、要約と相談場所の写真、状況選択、見本、カルテ利用実例、会社の仲介事例、相談対象の写真、担当者と場所、連絡とお渡しの流れ、フォーム、自分で整理する資料。
- 2026年9月の磐田市の農地相談を、運営者提供の事実だけで匿名掲載。
- 初回連絡は原則2営業日以内。運営者が本実装依頼の会話で対応可能と確認した。
- 受付日の翌営業日から数え、水曜・日曜・臨時休業日を除く。お渡し予定日は物件特定と必要情報の確認後に個別案内する。
- 受付完了画面、申込みページ、FAQ、実績ページ、担当者用雛形で案内をそろえる。

## 素材

- 応接室、スタッフ、外観、顔写真は既存の掲載素材を使用。
- ユーザー提供の `20261014173009019.pdf`（12件の成約事例一覧）から、北見町、見付、掛塚の物件写真部分をPDFレンダリングで抽出。
- ユーザー提供の `20261014174906657.pdf`（売却相談案内）から、代表の写真、古い住宅、家財の残る室内の写真部分を抽出。
- 原PDFはサイトに公開しない。画像はWebPに圧縮。画像の内容を生成・再構成していない。
- 会社事例の写真は、カルテ利用実績と表記しない。代表の写真を実際の相談風景と表記しない。
- 元資料の成約価格・売却期間は、算定条件の説明がないため今回のカードへ転記していない。対応の詳細は資料にある範囲に限定。

## 計測

- `page_version: photo-consultation-v1` を既存の列挙型メタデータに追加。
- 事例ページの閲覧は `karte_result_view`、入口のクリックは `karte_result_click` と `company_case_click` で別々に記録。`case_id` は公開済み事例の固定識別子のみ。
- フォーム完了の計上元と二重送信防止は既存処理を継続する。
- 個人の連絡先・住所・自由記入を計測へ渡さない。内部確認・localhost・プレビューの計測除外を継続する。
- 変更前後でデバイス・流入経路を分け、申し込み、連絡成立、自己整理ツール利用、対応負担を比較する。同時変更のため写真単独の効果とは断定しない。

## 受付担当者の記録

受付日時、初回連絡日時、物件・情報の確認完了日、お渡し予定日、実際の送付日を案件ごとに記録する。自動返信や受付完了画面の表示を担当者からの初回連絡に数えない。予定変更は予定日前に理由と新しい予定を案内する。

通知メールの送信先とフォームのAPIは既存のものを使う。新しい自動返信メールは追加していない。
