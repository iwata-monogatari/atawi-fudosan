# 実家カルテのトップ・申込み改修（2026年10月14日）

## 変更

- トップを7区画に整理。1階事務室と看板に合わせた円・普段の姿への切替は継続。
- カルテ見本と任意の状況選択を同じ区画にまとめ、未選択時は解説を出さない。
- 会社の3件の仲介写真は実績ページに維持。トップでは短い紹介とリンクに集約。
- 担当者と事務所を同じ区画へ。スタッフ集合写真と補助資料は任意で展開。
- 両フォームは市町村・町名・番地（任意）・連絡先を先にし、状況・名前・相談メモ等を任意欄にまとめる。比較メモと現地確認メモの引継ぎ・確認・解除は従来の処理を維持。
- `/karte/` は申込みに集中し、以前の顔だけのアップを既存の上半身写真へ変更。
- 営業方針が未確認の強い断言を、確認済みの「申込みだけで売却依頼にはならない」に整理。
- フォームの情報利用説明から「だけ」を外し、プライバシーポリシーの詳細と広告計測の説明を参照できる形にする。広告設定・送信先・データ送信を新規追加していない。
- 見本のボタンを「自分の実家について、カルテを依頼する」に変更。見本の切替を本人の状況に変換しない。タブの矢印・Home・End操作に対応。
- 対象となる相談導線だけ簡潔な共通フッターを使用。他の記事群は従来のフッターを継続。

## 実例と数値

農地事例は運営者提供の4事実（相談先不明、建築要件と引き渡しの条件、保有継続、2026年9月・磐田市）だけで整理。新しい行政確認・取引経過・家族の感想は追加していない。

集計期間が確認中だった外部の売却45件・買取4件は掲載を取り下げ、確認後に出典・期間・基準とともに復帰できる。2025年の27件は会社の公開記事の紹介とし、12月11日公表の情報を年末時点の通年実績と断定しない。

## 計測

新しいページ版は `consultation-streamline-v1`。既存の `form_consult` の完了計上元と重複防止は継続。トップはサーバー受付成功後、`/karte/` は直前の成功印を消費した完了ページが正本。広告コンバージョンも既存経路を維持。

- `sample_open_click`：見本への入口クリック。以前は一部で `sample_view` が使われていたため、変更日で区切って比較する。
- `sample_view`：見本ページのタブ表示。固定の `sample_id` と任意の状況分類だけ。
- `karte_application_form_view`：最初の必須設問が半分見えたセッション。
- `karte_application_form_start` / `city_select` / `contact_input` / `complete` / `submit_error`：既存のセッション重複防止を使い、両フォームで同じ段階を確認する。
- `application_success` と `form_consult` と段階イベントを足し合わせない。成功件数の正本は `form_consult`、運用の受付記録と照合する。
- 電話・LINEのクリックは相談成立ではない。連絡成立と初回連絡日時は受付担当者が別途記録する。

住所・連絡先・自由記入は計測へ渡さない。内部・プレビューの除外を維持。

## 継続して確認する事項

営業・継続連絡方針、広告管理画面の拡張コンバージョン設定、農地事例の確認過程、実際のカルテ納品日数は運営資料が必要。未確認の内容は新しい約束や実績として追加しない。新しい住宅の利用実例と新規撮影は、実際の素材が得られた段階で追記する。

## 検証

既存テストに加え、見本のキーボード操作・本人申告を上書きしない動作・電話のみの申込みを検証。公開事実のチェック、サイトマップと内部到達、HTMLと画像参照、PC・スマートフォンの表示を確認する。
