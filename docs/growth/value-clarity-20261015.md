# サービスの価値・読書量・納期説明の改修（2026年10月15日）

操作の正常動作だけで完了とせず、冒頭でサービスの価値が分かること、申込み前の読書量、納期の理解、確認済み事例の伝え方を今回の改修範囲とした。

## 実装

| 対象 | 実装内容 |
| --- | --- |
| 冒頭の価値説明 | 「家族で決めるための無料の調査レポート」と明記。価格の目安・課題・次の対応をPDFにまとめ、メール・LINEで受け取れることを冒頭に集約。 |
| 読書量 | 見本説明の重複を削減。実例を2枚の短いカードに整理。担当者の詳しい紹介を申込み後へ移動し、所在地・追加写真・会社情報は展開式に整理。担当者の顔と1階事務室は冒頭にも掲載。 |
| 納期 | 初回連絡とPDF送付を分けて表示。PDFの起点は「必要な情報と送付先がそろった日」。金曜にそろう→土曜が1日目→日曜までに送付、という図を追加。トップ・申込み専用ページ・FAQ・受付完了で同じ説明を使用。 |
| 実例 | 住宅は未登記→表題登記、接道の課題→接道の手続きの対応表。農地は確認した条件→保有継続の対応表。相談前の迷いと決めた方針を短く示す。 |

住宅（2025年10月・磐田市）と農地（2026年9月・磐田市）は、依頼者が確認した実家カルテ利用事例のみを使用した。手続き完了、売却成立、売却金額、所要日数、家族の発言・満足度は追加していない。見本は架空事例と明記し、実例とは区別した。
