# 実家の片付け・解体 比較メモ作成ツール

公開先 `/jikka/katazuke-kaitai/memo/`。2026年10月12日作成の企画書・作成指示書に基づく初版。

## 入力と比較

登録不要で家の状況・費用・家族の希望を任意入力する。古家のまま、片付けて、解体して売る3案に、残置物処分・建物解体・庭木外構等・測量境界・その他の5費目を並べる。共有する検証・集計は `assets/jikka-memo-core.mjs` が担当し、Pages Functionも同じモジュールを読む。

税込と確認された入力金額だけを小計。未確認、税込確認待ち、別費用に含む、今回の案で行わないを区別し、売却価格・手残り・税額を自動計算しない。印刷はブラウザーの印刷機能によるA4一枚の要約。次の確認事項は最大3件と残件数を印刷し、全件は結果画面で確認できる。

## 引継ぎと保持

通常は画面メモリのみ。結果で本人が添付を選んだ場合、同じタブのsessionStorage専用キー `atawi_jikka_memo_handoff_v1` に、構造化メモと作成時刻を保存する。有効期間30分を読込み・送信前・画面復帰・表示中のタイマーで検証し、期限切れを送信に使わない。ブラウザーが閉じられた後に時刻通りに消去される保証はしない。

`/karte/?entry=…&concern=…&memo=1#apply` へ移動し、内容を再確認できる。金額や自由記入はURLに入れない。添付解除と送信成功時に専用キーだけを削除する。通知失敗時は有効なメモを保持し、自動再送しない。通常フォームの500文字メモとは別の `comparisonMemo` 任意項目としてPOSTする。入力中や印刷時には本文をサーバーに送らない。

サーバーは16KiBの上限と全スキーマを検証し、メール用の小計・確認事項を再計算する。不正メモは400。通知先は従来のResend宛先を維持。ログは処理状態と技術的エラーのみとし、入力データや通知サービスのレスポンス本文を記録しない。

## 計測と受付

- `jikka_memo_start`：最初の入力変更、一画面利用で1回
- `jikka_memo_result_view`：初回の結果表示
- `jikka_memo_print_requested`：印刷ダイアログの要求。保存・印刷完了ではない
- `jikka_memo_consult_click`：有効なメモを添えてフォームへ移動
- `jikka_memo_application_success`：メモ付きAPIが通知サービスの受付成功を返す

メタデータは固定のtool・step・entry・concernのみ。既存のフォーム完了はthanksが唯一の計上元であり、新イベントと合算しない。内部・自動操作・プレビューの計測を除外する。受付後は入力金額を未検証情報として扱い、本人の希望と確認事項から応答する。同一物件は既存の非公開案件管理でまとめ、物件特定・現地確認・売却相談・媒介契約を分けて記録する。30・60・90日で利用状況を見直す。
