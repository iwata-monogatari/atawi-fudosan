# 課税明細書の見本図（2026-11-01）

全12フォームの住所・番地欄直下の共通案内へ見本図を追加。
所在地・地番の2欄を太枠と矢印で示し、「ここが所在地・地番です」と表示する。
「○○市 見本町」「123番4」は架空の例。個人の課税資料や自治体の書式を転載せず、税額・所有者情報は掲載しない。欄名・書式が自治体によって異なることを図中にも表示。

図は拡大しても文字が鮮明なSVG。入力幅に合わせて縮小し、リンクから原寸の図を別タブで確認できる。画像の代替テキストと既存の文章による説明を併用する。

共通原稿 `_tools/property-address-help.mjs` と全フォームの一致検査、画像ファイル存在検査、LP再生成での共通原稿利用により、再生成時の欠落を検出する。
