# Googleビジネスプロフィール（GBP）運用プレイブック

作成 2026-10-12。対象：富士ヶ丘サービス株式会社（磐田市見付5789番地1）の GBP。
目的：Google マップ検索と AI 検索（Google AI モード・ChatGPT・Gemini・Perplexity）の両方で
「磐田・袋井の実家・空き家相談ならここ」と判断される材料を、サイト外に積み上げる。

GBP は Search Console では見えない。ここで週1回・月1回の作業を固定する。

---

## 1. 最初に1回だけ整える（所要30分）

business.google.com で以下を確認。空欄が1つでもあると AI は「情報が薄い会社」と判断する。

| 項目 | 入れる内容 |
|---|---|
| ビジネス名 | 富士ヶ丘サービス株式会社（サイト・ポータルと同一表記。「ATAWI」等の装飾を付けない） |
| メインカテゴリ | 不動産業者 |
| 追加カテゴリ | 不動産コンサルタント、高齢者向け住宅（サ高住を運営している事実に基づく） |
| サービス提供地域 | 磐田市、袋井市、周智郡森町、掛川市、菊川市、御前崎市、湖西市、浜松市 |
| 電話 | 0538-31-3308 |
| ウェブサイト | https://fudosan.atawi.link/ |
| 予約リンク | https://fudosan.atawi.link/karte/ （実家カルテ申込） |
| 営業時間 | 月火木金土 9:00–18:00（サイトの JSON-LD と同じ） |
| 説明文（750字） | 下の「説明文テンプレ」を貼る |
| サービス | 実家カルテ（無料）／相続不動産の売却相談／空き家の売却・賃貸相談／施設入居後の実家整理／戸建て賃貸（管理費0円） |
| 属性 | 「オンライン相談可」「予約推奨」 |
| 写真 | 外観・入口・事務所内・代表者の写真を各1枚以上。実家カルテの見本（/karte/sample/）のスクリーンショットも可 |
| Q&A | 自分で質問を5件投稿して自分で回答する（下の「Q&A初期セット」） |

### 説明文テンプレ（750字以内）

```
富士ヶ丘サービス株式会社は、静岡県磐田市で介護事業（サービス付き高齢者向け住宅）と不動産仲介を営む会社です。親の施設入居、相続、空き家など「まだ売ると決めていない実家」の整理を、宅地建物取引士の代表が直接担当します。

無料の「ふじがおか実家カルテ」では、住所から名義・道路・境界・農地・災害情報を机上で確認し、売る・貸す・残すのどれを選ぶにも使える材料をお渡しします。相続登記が終わっていない、荷物が残ったまま、県外にお住まい、という状態のままご相談いただけます。強引な売却営業は行いません。

対応地域：磐田市・袋井市・森町・掛川市・菊川市・御前崎市・湖西市・浜松市
宅地建物取引業免許：静岡県知事(2)第14083号
```

### Q&A 初期セット（自問自答で投稿）

1. 売ると決めていなくても相談できますか？ → できます。実家カルテは売却が前提ではありません。
2. 相続登記が終わっていなくても相談できますか？ → できます。登記情報と固定資産税通知書から現在の状況を整理するところから始めます。
3. 県外に住んでいても対応してもらえますか？ → 対応できます。物件が対応地域内にあれば、依頼者の居住地は問いません。
4. 査定や実家カルテに費用はかかりますか？ → かかりません。外部の専門家への依頼（測量・解体見積・登記）が必要な場合は、事前に内容と費用をお伝えします。
5. 荷物が残ったままの家でも相談できますか？ → できます。写真と住所から机上確認を始められます。

## 2. 口コミを集める仕組み（毎回の案件で）

口コミは「数」より「本文に地名と状況が書かれていること」が AI には効く。
依頼者に書いてもらうタイミングと文面を固定する。

### 依頼のタイミング（3か所に固定）

| タイミング | 渡し方 |
|---|---|
| 実家カルテをお渡しした直後 | カルテ送付メール／LINE の末尾に依頼文を付ける |
| 売買契約・決済が終わった日 | 対面でカードを渡す（QRコード付き） |
| 賃貸の入居が決まった日 | 同上 |

### 口コミ投稿リンクの取り方（1回だけ）

business.google.com → ホーム → 「クチコミを依頼」 → 表示される短縮URL（g.page/r/…/review 形式）をコピー。
以下のテンプレの `{{REVIEW_URL}}` に差し替える。QRコードは同画面で画像保存できる。

### 依頼文テンプレ（LINE／メール）

```
このたびはご相談ありがとうございました。
よろしければ、Google の口コミに「どんな状況で相談したか」「何が整理できたか」を
一言いただけると、同じ状況で迷っている方の参考になります。
{{REVIEW_URL}}
（星の数は気にされなくて結構です。率直なご感想をお願いします）
```

### 依頼文テンプレ（紙カード・名刺サイズ）

```
富士ヶ丘サービス｜ご相談ありがとうございました
Google 口コミで「相談した状況」を一言お聞かせください
[QRコード]
相続・空き家・施設入居後の実家｜磐田市見付5789-1｜0538-31-3308
```

### 書いてもらうと効く内容（依頼時に口頭で添える）

- どの市町の実家か（磐田市○○、袋井市○○）
- どんな状況だったか（施設入居後・相続登記前・荷物が残ったまま・県外在住）
- 何が整理できたか（売らない判断になった、でも可）

## 3. 口コミへの返信（届いたら48時間以内・全件）

返信は Google にも AI にも読まれる本文。依頼者名は書かず、状況と地名を自然に繰り返す。

### 返信テンプレ（良い評価）

```
ご相談ありがとうございました。{{市町}}のご実家について、{{状況：施設入居後／相続登記前／荷物が残ったまま}}の状態から
一緒に整理させていただきました。今後も{{次の段階：管理／売却／賃貸}}で確認したいことが出てきましたら、
いつでもご連絡ください。富士ヶ丘サービス 大石
```

### 返信テンプレ（厳しい評価）

```
ご指摘ありがとうございます。{{該当する点}}について、ご期待に沿えず申し訳ありませんでした。
{{改善すること}}を見直します。差し支えなければ 0538-31-3308 まで直接お聞かせください。富士ヶ丘サービス 大石
```

言い訳・反論・個人情報（物件の所在や契約内容）は書かない。

## 4. 週1回の投稿（毎週月曜・5分）

```bash
python -X utf8 _tools/gbp-weekly-post.py
```

`docs/growth/gbp/YYYY-MM-DD-post.md` に本文と手順が出る。business.google.com の「最新情報を追加」に貼り、写真1枚とリンクボタンを付けて投稿する。
投稿は「最新情報」で統一（「イベント」「特典」は使わない）。地名と状況語（実家・空き家・相続・施設）が本文に入っていることを確認する。

---

## 5. 月1回の確認（毎月1日・15分）

GBP の「パフォーマンス」で以下を記録（kpi/ai-visibility/log.csv の GBP 列）：

- 検索での表示回数（ビジネス名検索／カテゴリ検索の内訳）
- ウェブサイトへのクリック、電話、ルート検索
- 口コミ件数と平均評価、未返信の有無
- 「ビジネス情報の提案」（Google からの修正提案）が来ていないか → 来ていたら承認か却下

---

## 6. やらないこと

- 口コミの代筆・見返りの提供（Google ポリシー違反。表示停止のリスク）
- 社員・家族による投稿
- 投稿へのキーワード詰め込み（「磐田市 不動産 売却 相続 空き家 …」の羅列）
- ビジネス名への地名やサービス名の追加
