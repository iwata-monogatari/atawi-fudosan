LOCAL PROPERTY CHECK

磐田市・袋井市の実家で
確認する6項目

全国共通の一般論だけでは、実家の判断は進みません。登記、市の道路資料、農地の区域、最新ハザードマップなど、物件の場所に結び付く情報を確認する入口を一枚にまとめました。

01 名義

所有者と相続登記

固定資産税通知書だけで所有者を確定せず、土地・建物の登記事項を確認します。相続登記の期限と、宅地以外の筆が付いていないかも同時に整理します。

地域の入口：静岡地方法務局磐田出張所、磐田市・袋井市の空き家相談窓口

磐田市・袋井市の相続登記を詳しく読む →
02 権利

共有・抵当権・相続人

きょうだい共有、古い抵当権、所在が分からない共有者があると、売却や活用の前提が変わります。登記の名義と家族が理解している権利関係を照合します。

地域の入口：静岡地方法務局磐田出張所。個別判断は司法書士・弁護士へ確認

磐田市・袋井市の共有名義を詳しく読む →
03 接道

道路種別・幅員・再建築

地図上で道に面していても、建築基準法上の道路とは限りません。道路台帳の幅員と現地を照合し、セットバックや再建築条件は市の担当窓口へ確認します。

地域の入口：磐田市・袋井市の道路台帳、建築担当窓口、袋井市「どまんなか袋井navi」

袋井市GISで道路を確認する方法 →
04 境界

境界標・公図・測量図

境界標の有無、公図と現況のずれ、地積測量図の有無を確認します。公簿売買か実測売買かは、資料と現地の状態を見て決めます。

地域の入口：法務局の公図・地積測量図、磐田市・袋井市の地籍調査成果

磐田市・袋井市の境界と測量を詳しく読む →
05 農地

地目・青地白地・農地法

登記地目が田畑なら、農地のまま譲るのか、転用するのかで手続きが分かれます。農用地区域内かどうか、農振除外が必要かを先に確認します。

地域の入口：磐田市・袋井市の農業委員会、農林担当窓口。許可可否は計画を示して確認

磐田市南部の青地・白地を詳しく読む →
06 災害

洪水・土砂・津波・履歴

ハザードマップの色だけで売れる・売れないを決めません。想定浸水深、避難先、過去の浸水履歴、保険の条件を分けて説明できる状態にします。

地域の入口：磐田市デジタルハザードマップ、袋井市洪水・土砂災害ハザードマップ

磐田市・袋井市の水害リスクを詳しく読む →

6項目を、その家に合わせて整理します
